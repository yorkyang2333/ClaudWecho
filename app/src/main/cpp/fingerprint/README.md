The fingerprint algorithm is the unmodified WASM module distributed with the [upstream audio matching example](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/tree/2db6684453297ee86dec0492842f2320b08182d9/public/audio_match_demo), converted to C using WABT 1.0.42. Its distribution license is retained in LICENSE.algorithm; WABT's license is retained in LICENSE.wabt and the runtime source headers.

To regenerate afp.c, afp.h, and the runtime support, put WABT 1.0.42's wasm2c on PATH and run `python3 scripts/generate_audio_fingerprint.py` from the repository root. Normal Android builds use the checked-in C sources and require neither WABT nor a network download.

The host captures ExtractQueryFP's invoker and target from the module's binding registration, supplies the same length-prefixed Float32 byte buffer as the JavaScript example, and copies the resulting vector bytes. Registration does not require a JavaScript engine. Unexpected JavaScript-dependent calls and Wasm traps fail the operation. Every request releases its complete linear memory and table. Explicit bounds checking avoids large virtual memory reservations and signal handlers; floating-point contraction is disabled to preserve Wasm arithmetic.
